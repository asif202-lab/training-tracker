Staff roster

Upload the staff CSV (columns: identification_id, employee_name, company_joining_date, department_name — date of birth is optional, see note below). This is what staff use to log into the daily quiz with just their Employee ID, and it also powers the service-anniversary recognition on the overview page.

Training programs

Upload a training program file (.json — sections/topics, one or more phases). This is what fills the Program dropdown when adding a trainee. Uploading a file with the same program ID replaces it; deleting a program does not delete trainees already on it, but their checklist will show "Program not found" until reassigned.

Exam bank

Upload an exam file (.json) to make it available online. Uploading a file with the same exam ID replaces that exam. Edit the pass mark, time limit (0 = no limit) or retake gap (days to wait after a fail) by changing the number. Pass mark changes apply to all results of that exam.
